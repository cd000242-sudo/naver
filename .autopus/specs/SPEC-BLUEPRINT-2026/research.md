# SPEC-BLUEPRINT-2026 — 조사 (2026-09-04)

## 질문
"애초에 글 자체를 수정할 필요 없게 생성하려면 어떻게 해야 하나." (사장님, 2026-09-04 02:00)
전제: 이 툴의 가치는 사람 손 없이 홈판·상위노출급 글을 자동으로 내는 것. "내보낼 만한 글"은 기준이 아니다.

## 오늘 실측에서 나온 사실

### 1. 모델은 규칙은 흘리고 재료는 쓴다
| 요구 | 규칙으로 시켰을 때 | 재료·구체 지시로 줬을 때 |
|---|---|---|
| 직접 인용 | 2회 생성 모두 0건 (GPT-5.6 Terra) | 재료 발언 5개를 지시문에 넣자 3건 (같은 엔진) |
| 도입부 독자 상황 | Gemini 3.6 · GPT-5.6 · Claude Code 전부 분석형 예고문 | 패치에 "고칠 점"을 적어 주자 1회에 "…헷갈릴 때예요" |
| 자료 목록 서술 금지 | 프롬프트에 금지 예시 있어도 gpt-4.1 이 재발 | finalize 에서 문장 제거(materialNarrationStrip) |

### 2. 프롬프트는 65,723자, 재료가 절반 가까이
- 홈판 GPT 호출 프롬프트 65,723자(에이전트 봉투 포함 68,647자). 그중 재료(사실 자료 블록) 24~30K자, 규칙 약 40K자.
- 재료는 원문 통째 주입이라 곁가지가 그대로 들어간다: 청년도약계좌 글에 청년미래적금 통계 더미, 전세 글에 장기전세주택 퇴거 통계.
- 큰 프롬프트에서 작은 규칙(첫 문장 형태, 인용, 목록 서술 금지)이 묻힌다. 엔진을 올려도(3.6 flash 58점 → GPT-5.6 77점) 같은 지적이 났다 → 파이프라인 문제.

### 3. 게이트는 거의 매번 발화한다
- 홈판 GPT-5.6 검증 4회 중 4회 재생성 또는 patch. 재생성 1회 + 자기비평 1회 = 본문 호출 2회 + 소보정. 비용·시간이 두 배.
- 그중 2회는 검사기 오탐(천원 표기·연도)이 안전 점수를 35로 끌어내려 부른 것 — 오늘 수정. 남은 오탐: 감정 키워드 누락 휴리스틱(정치 의혹 글에 "진심·진정성 누락"을 환각 신호로).

### 4. 출력 스키마에 있는데 아무도 안 쓰는 필드
- `readerSituation`(독자가 이 글을 만나는 상황) — contentJsonPromptFormat 이 요구하고 모델이 채우지만 src 어디서도 소비하지 않는다. 도입부와 묶여 있지 않아 모델이 채워 놓고도 도입부는 예고문으로 쓴다.
- `evidence`(근거 인용) — 같은 상태.

### 5. 이미 있는 자산
- URL 모드 1단 분석(`paraphraseSourceAnalysis`): clickReason · mainKeyword · subKeywords · skeleton · evidenceAnchors · gaps 를 JSON 으로 뽑고 본문 프롬프트에 브리프로 붙인다. "분석 → 집필" 2단이 이미 한 경로에 있다.
- 에이전트 봉투(`agenticEnvelope`): 분석 → 초안 → 자기비평 → 수정을 CLI 안에서 돈다. API 엔진에는 이 단계가 없다.
- `quoteCoverage.extractDirectQuotes`(재료 발언 추출), `materialTierNotice`(재료 급 표시), `resolveSelectedEngineRoute`(보조 호출도 고른 엔진), 게이트·재생성·패치(오늘 기본 ON).

## 제약 (변경 불가)
- 자동 폴백 금지(엔진을 몰래 바꾸지 않는다). 발행 차단 게이트 신설 금지(경고만). 하드코딩 금지, 사용자 키 원칙.
- god file(contentGenerator.ts) 계약 테스트: finalize 반환 라인 핀, V3 wiring, 지문 핀, 레거시 베이스라인(프롬프트·평가기 바이트).
- 파일 300줄 상한, 테스트 우선, 1릴리즈 1~3 fix(단계 분할).
- 비용: 통과 글 추가 비용 0 유지. 미달 글 재생성 1회 상한 유지.

## 결론
규칙을 더 쓰는 방향은 한계다. 본문 호출 전에 **짧은 설계도**(독자 상황·인용 후보·근거 사실·골격·제외 주제)를 뽑아 그것을 재료로 주고, 스키마 필드를 조립 코드가 실제로 소비하게 묶어야 첫 호출에서 형태가 잡힌다. 게이트는 보험으로 남긴다.
