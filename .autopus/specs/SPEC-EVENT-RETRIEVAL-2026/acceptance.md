# SPEC-EVENT-RETRIEVAL-2026 수용 기준

## Phase 1

| # | 기준 | 검증 방법 |
|---|---|---|
| A1 | 실측 사례에서 송영진 계열 자료가 강등된다 | 그 자료 텍스트를 고정 표본으로 넣은 단위 테스트 |
| A2 | 김서현·김영웅 자료는 유지된다 | 같은 테스트 (미탐 방지) |
| A3 | 인물 0명·날짜 0개 겹침일 때만 강등된다 | 경계 테스트 — 인물 1명만 겹쳐도 유지 |
| A4 | 강등은 삭제가 아니다 — `offTopic[]` 으로 넘어간다 | 반환값 단언 |
| A5 | 강등 사유가 로그에 남는다 | 로그 문자열 단언 |
| A6 | 기존 게이트 4곳 동작 불변 | `supplementTopicGuard` 관련 기존 테스트 GREEN |
| A7 | 자료 총량이 줄지 않는다 | Phase 0 표본 대비 재계산 |
| A8 | 전체 vitest GREEN, tsc 0, eslint 0 errors | 실행 증거 |

## Phase 2

| # | 기준 | 검증 방법 |
|---|---|---|
| B1 | 실측 사례에서 `김영웅` 이 다리 엔티티로 잡힌다 | 고정 표본 단위 테스트 |
| B2 | 분해 질의는 키워드 안 엔티티 조합만 쓴다 | 바깥 낱말이 나오면 실패하는 테스트 |
| B3 | 확장 깊이는 3차에서 멈춘다 | 호출 카운트 단언 |
| B4 | 호출 상한을 넘지 않는다 | 모의 호출 카운터 |
| B5 | 일반 키워드 경로가 변하지 않는다 | 토글 OFF 시 종전 호출 시퀀스 동일 |
| B6 | 확장 실패해도 글은 나온다 | 빈 결과 주입 시 정상 반환 |

## 공통 금지

- 게이트를 발행 차단으로 만들지 않는다
- 자동 엔진 폴백 없음
- 하드코딩된 모델·키 없음
- 유료 재실행으로만 검증되는 기준을 두지 않는다
