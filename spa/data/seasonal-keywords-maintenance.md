# 시즌별 키워드 모음

`/leword?tab=seasonal`은 애드센스 벤치마크 다음의 이용권 탭이다. 공개 보드를 사용하는 기존 탭과 같은 로그인 정책을 따른다. UI가 열릴 때만 자료를 요청한다.

## 자료와 재발행

- `seasonal-keyword-research.json`: 편집 검토한 주제, 실제 네이버 자동완성 응답의 검색 표현·조회 URL·관측 시간. 검색량이나 검색 피크 자료가 아니다.
- `seasonal-coverage-audit.md`: 기존 앱의 두 시즌 목록과 대조한 누락·중복·비정기 항목 검토 기록.
- `../public/data/seasonal-keywords.json`: 공개용 파생 데이터. 원본에 없는 수요·수익 지표를 생성하지 않는다.

사이트 저장소 루트에서 `node spa/scripts/build-seasonal-keywords.mjs`로 재생성한다. 생성기는 이전 연도 표현, 공백·대소문자 중복, 비정상 텍스트를 제거한다. 의미 관련성 자동 판정은 하지 않는다. 검토일은 실제 검토 때에만 갱신하고 단순 빌드로 최신 조사처럼 표시하지 않는다.

`node --test spa/tests/seasonal-keywords.test.mjs spa/tests/seasonal-publication.test.mjs`는 실제 보드 파싱, 원본에서의 재현성, 12개월 범위, 필터·연말 전환·페이지·실패 재시도를 검증한다. 배포 워크플로에도 연결했다.

## 편집 규칙

기획 월과 검색 피크, 신청·지급·사용 마감은 다른 개념이다. 별표는 한국 날짜 기준 이번 달/다음 달의 기획 후보이고 황금키워드 등급이 아니다. 다음 연도에도 모집 중이라는 배지를 자동 부여하지 않는다. 지원사업은 공고, 명절은 음력, 학교·기업 일정은 주최 측 자료가 우선이다.

일반 포털은 발행 전 확인처로 표시한다. 직접 공고를 검토한 항목도 해당 연도·대상의 확인 범위만 인정한다. 검색량·문서량·광고 수는 현재 미측정이며 분석 탭으로 넘겨 확인한다. 네이버 광고 수와 애드센스 광고 요청 수를 같은 지표로 취급하지 않는다.

2026-10-16 배포 자료: 기존 288개에 누락 77개를 더한 365개 기획 주제. 정제 후 자동완성 고유 표현 1,716개, 세금·지원금·노무 137개. 전국 지역별 사업·축제 및 모든 제품별 세부 검색어의 전수 목록은 아니다.
