### 아직 개별 최신 공고를 검증하지 않은 항목

공무원 시험·자격 시험·지자체 광견병 지원·근로자 휴가지원·자연휴양림 추첨·공연 예매 등의 **당해 연도 실제 일정, 모집 여부, 가격**은 이번 보완에서 확정하지 않았다. 해당 항목은 `공고형`과 확인할 사항을 명시한 후보로 유지한다. 홈페이지 확인처가 있다는 것만으로 '공식 일정 검증 완료'로 표시하면 안 된다.

건강보험 보수총액 신고는 사업장 절차라는 별도 수요를 추가했지만, 간이지급명세서 연계 등 변화가 있으므로 화면에서 일률적인 제출 의무나 3월 10일 확정 마감을 직접 표시하지 않는다. 해당 연도 공단 사업장 안내 확인이 필요하다.

## 사이트 반영 시 중요한 구분

1. 월은 **기획 시즌**이다. 검색량 최고점이나 모든 행사의 실제 개최월이 아니다. 음력 명절과 신청·지급 회차는 해당 연도 공고에 따라 이동한다.
2. 자동완성 수집 성공은 검색어 존재 확인이다. 검색량, CPC, 광고주 수요, 검색 상위 진입 확률을 입증하지 않는다.
3. 검색량·문서량·광고 지표가 없으면 `미측정`으로 표시한다. 빈 값을 0으로 바꾸거나 황금키워드 등급을 생성하지 않는다.
4. `광고 수`(평균 노출 광고 수), 입찰가, 애드센스 광고 요청 수는 서로 다른 지표다. 광고 요청 수는 해당 키워드의 광고주 수요를 직접 뜻하지 않는다.
5. 계절 준비 시점과 신청 중·마감 임박 상태를 분리한다. 2026년 공고를 근거로 2027년에 `신청 가능` 배지를 자동 부여하지 않는다.
6. 출처 버튼은 확인용 포털과 직접 공식 공고를 구분한다. 공고형은 직접 공고를 다시 확인하기 전까지 모집 중으로 표시하지 않는다.
7. 앱의 기존 `peak` 배열에는 실측 시계열이라는 보장이 없다. 이를 사이트의 `검색 피크`로 그대로 노출하지 않는다.

## 잔여 범위와 위험도

- 낮음: 명절·절기·계절의 반복을 이용한 기획 후보와 글쓰기 방향.
- 중간: 날씨·개화·축제·예약·기업 일정. 운영 주체의 최신 공고와 당일 상태가 필요하다.
- 높음: 세금·보험·지원금의 자격·금액·마감. 직접 공식 자료, 적용연도와 개인 조건 검증이 필요하다.
- 미포함: 전국 지자체 개별 축제·바우처·단기 예산사업 전수, 모든 제품별 모델·지역 롱테일. '모든 시즌키워드를 빠짐없이 수집했다'고 주장할 수 없다. 대신 반복 주제의 넓은 범위와 어디까지 확인했는지를 공개한다.

추가 77개 전체의 출처 매핑은 `source-overrides.json`에 별도로 작성했다. `kind: official_reference`는 해당 관련 공식 자료를 확인한 9개이며, 그 외는 `confirmation_portal`로 표시했다. 전자는 해당 키워드의 모든 조건·검색 수요가 검증됐다는 뜻이 아니다.

담당 변경 파일은 `additions.txt`, `coverage-audit.md`, `source-overrides.json`이다. 앱 원본 시드와 보고서 기존 데이터는 변경하지 않았다.
