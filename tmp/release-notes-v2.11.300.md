## v2.11.300 — 연속발행 이미지 설정 중복 정리

### 고침
- **연속발행 이미지 설정 중복** — v2.11.299 에서 연속발행 패널에 새로 생긴 "이미지 전략 / 소제목 범위 / 썸네일 문구" 칸을 없앴습니다. 이 칸이 기존 "⚡ 이미지 세팅하기"와 "썸네일 텍스트 포함" 설정을 덮어써서, 소제목 이미지를 홀수·짝수·썸네일만으로 설정해 둔 경우에도 연속발행 글은 소제목 전체에 이미지를 만들었습니다. 이제 예전처럼 기존 설정을 따릅니다.
- **썸네일 문구 설정을 하나로** — "메인 풀오토 이미지 설정" 창에 따로 생긴 썸네일 문구 선택을 없애고 "썸네일 텍스트 포함" 체크박스 하나로 정리했습니다. 체크하면 짧은 문구를 넣습니다. 꺼 두면 완전자동·예약(홈판/피드 최적화)은 자동으로 정합니다: 제품·여행 글은 숫자·발언이 있을 때만, 나머지 글은 제목에서 뽑은 짧은 문구를 넣습니다.

### 그대로
- 이미지 전략(홈판/피드 최적화 · 내 이미지 설정)은 "메인 풀오토 이미지 설정" 창에서 고릅니다.
- 800x800 홈판 이미지, 이미지 검토 보류, 예약 큐 상태 표시는 v2.11.299 그대로입니다.
