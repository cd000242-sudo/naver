## v2.11.317 — 네이버 보호조치 방지: 자동 비밀번호 로그인 중단

### 바뀐 점
- **앱이 더 이상 비밀번호를 자동으로 넣지 않습니다.** 발행할 때 네이버 로그인이 풀려 있거나 본인확인·보호조치 화면이 나오면, 로그인을 시도하지 않고 그 계정의 작업을 멈춥니다. 발행할 때마다 비밀번호로 다시 로그인하던 것이 보호조치의 원인이었습니다.
- **멈춘 계정 다시 시작하기** — 계정 카드에서 [네이버에서 확인하기]로 창을 열어 직접 로그인·본인확인을 마친 뒤 [확인 후 재개]를 누르세요.
- **다중계정·연속발행** — 한 계정이 멈추면 대기열 전체를 멈춥니다. 다른 계정으로 넘어가 계속 발행하지 않습니다.
- **로그인 유지** — 로그인이 확인될 때마다 저장해, 앱을 다시 켜도 로그인 상태가 이어집니다. 업데이트 직후 로그인이 풀려 있다면 한 번만 직접 로그인해 주세요.
- **중복 발행 방지** — 발행 버튼을 누른 뒤 결과가 확실하지 않으면 다시 발행하지 않고 멈춥니다. 네이버 글 목록을 확인한 뒤 [발행됨 확인] 또는 [발행 안 됨 확인]을 누르세요.
- **계정 확인** — 같은 계정이 두 작업에서 동시에 돌지 않고, 고른 계정과 실제 로그인한 계정이 다르면 멈춥니다.
- **발행 기록 파일이 손상되면** 계정 카드에 [발행 기록 초기화]가 나옵니다. 기존 파일은 지우지 않고 옆에 보관합니다.

### 라이브 미검증
자동 테스트와 릴리즈 게이트로 검증했습니다. 실제 네이버에서 로그인이 만료된 계정이 멈추는 흐름과 앱 재시작 뒤 로그인 유지는 이번 버전에서 확인합니다.
