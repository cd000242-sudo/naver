## 썸네일 문구 · 붙여 넣은 표 · 홈판 제목

### 고친 것
- "썸네일에 문구 넣기"를 꺼도 문구가 들어가던 문제를 고쳤습니다. 이제 체크가 켜져 있을 때만 넣습니다. 꺼 두면 이미지 탭, 풀오토, 연속 발행, 다중 계정 모두 문구 없이 만듭니다.
- ChatGPT · Claude 로 쓴 글을 붙여 넣어 발행할 때 표가 문장으로 풀려 올라가던 문제를 고쳤습니다. `구분 | 내용 | 내용` 처럼 줄마다 막대로 나눈 표도 표로 올라갑니다.
- 홈판 글에서 숫자가 든 좋은 제목이 "잘못된 제목"으로 판정돼 다른 제목으로 바뀌던 문제를 고쳤습니다. 키워드와 제목의 영문 대소문자가 달라도 같은 낱말로 봅니다.
- Claude API 로 글을 쓸 때 글 설계 단계가 "응답을 읽을 수 없어 생략"으로 빠지던 경우를 줄였습니다.

### 바뀐 것
- 홈판 글의 제목 후보를 고를 때, 질문으로 끝나는 제목에 주던 가점을 없애고 숫자 · 금액 · 등급이 든 제목을 더 높게 봅니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
