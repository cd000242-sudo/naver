## 글 생성 속도 2단계

### 글 생성
- 제목이 이미 정해진 글(키워드를 제목으로 그대로 쓰기, 직접 입력한 제목, 심사에서 고른 제목으로 다시 쓰는 글)에는 제목 고쳐 쓰기를 부르지 않습니다.
  - 고쳐 쓴 제목은 어차피 정해진 제목으로 되돌아가서 버려지고 있었습니다. 모든 엔진에 해당합니다.
- 에이전트 모드(Claude Code · Codex)에서는 SEO · 홈판 글의 제목 고쳐 쓰기를 따로 부르지 않습니다.
  - 에이전트가 글을 쓰는 같은 세션에서 제목을 정하기 때문입니다. 제목 점검 결과는 지금처럼 기록에 남습니다.
- 홈판 제목 심사 단계마다 걸린 시간을 기록에 남깁니다(예: "[TitleReview] stage=candidates 37.4s"). 남은 느린 구간을 실측으로 찾기 위해서입니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
