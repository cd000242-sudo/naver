## v2.11.307

반복되던 자동 로그인과 로그인 지연, 이미지 스튜디오 문구, 오늘의 글감 불러오기를 고쳤습니다.

- **하루에도 몇 번씩 다시 로그인하던 문제.** 발행 직전에 세션이 살아 있는지 확인하는 점검이 로그인된 상태에서도 한 번도 통과한 적이 없었습니다(점검용 주소가 로그인 여부와 무관하게 404를 돌려주고 있었습니다). 점검 1회 실패 = 비밀번호 로그인 1회였고, 이것이 잦은 보호조치의 원인이었습니다. 실제 에디터로 이동할 때와 같은 주소로 점검하도록 바꿨습니다.
- **로그인 성공 판정의 구멍 두 개.** 보호조치 해제 안내 페이지를 로그인 성공으로 읽어 쿠키를 저장하고 그대로 진행하던 것, 그리고 보호조치 감지 코드가 그 앞 단계에서 이미 빠져나가 한 번도 실행되지 않던 것을 함께 닫았습니다. 이제 이런 페이지를 만나면 "보호조치/본인인증 페이지 감지" 로 알립니다.
- **로그인 창에서 비밀번호 눈 버튼이 안 먹던 것.** 같은 이름의 옛 함수가 번들에서 진짜 핸들러를 가리고 있었습니다.
- **로그인부터 제목 입력까지 걸리던 시간을 줄였습니다.** 봇 회피용 대기(타이핑 속도, 로그인 후 자연 대기, 세션 워밍업, 초안 팝업 재확인)는 그대로 두고, 이미 끝난 일을 다시 기다리던 세 구간만 없앴습니다. ① 네이버가 로그인 버튼의 HTML 을 바꿔 앱이 등록해 둔 버튼 주소가 전부 빗나가던 것(버튼을 못 찾아 대체 방법으로만 눌리고 있었습니다) ② 이미 로그인 페이지를 벗어난 것을 확인하고도 페이지 이동을 20초 더 기다리던 것 ③ 세션 워밍업이 이미 블로그 홈에 들어가 있는데 워밍업을 한 번 더 돌던 것.
- **이미지 생성 스튜디오에서 "텍스트 포함" 을 켜면 "이미지 생성 스튜디오" 라는 글자가 그려지던 문제.** 스튜디오가 이미지 설명을 비워 보내고 화면 이름만 넘겨서, 그림에 넣을 유일한 한글 제목이 그 이름이었습니다. 이제 입력한 프롬프트에서 뽑은 문구가 들어갑니다.
- **키워드로 생성의 "오늘의 글감 불러오기" 가 며칠째 같은 목록만 보여주던 것.** 사이트의 최신 브리프를 읽도록 고치고, 출처별로 접었다 펼 수 있게 했습니다.
