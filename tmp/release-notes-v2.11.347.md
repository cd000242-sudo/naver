## v2.11.347 — 로그인 멈춤 자동 재개 · 오른쪽 버튼 정리 · 바로가기 버튼 위쪽으로

### 바뀐 점
- **로그인이 필요해서 멈췄거나 다른 계정으로 로그인되어 멈춘 경우, 열려 있는 네이버 창에서 로그인을 마치면 앱이 스스로 알아채고 멈춤을 풉니다.** [확인 후 재개]를 따로 누르지 않아도 됩니다. 앱은 창을 4초마다 읽기만 하며, 대신 클릭하거나 입력하거나 비밀번호를 넣지 않습니다. 풀린 뒤 발행 버튼은 직접 다시 눌러야 합니다. 앱이 자동으로 다시 발행하지는 않습니다.
- 본인확인·보호조치·연결 확인·발행 결과 확인 때문에 멈춘 경우는 지금처럼 직접 [확인 후 재개]를 누릅니다. 네이버 창이 이미 열려 있으면 [확인 후 재개]가 앞에 강조되어 나오고, [네이버 창 열기]는 "네이버 창 보기"로 바뀌어 뒤에 놓입니다.
- **오른쪽 버튼 모음(라이선스 · 카톡문의 · 환경 설정 · 가이드 · 초기화 · 사용법 영상 · 오류 진단 · 황금키워드)을 같은 크기로 맞췄고, 스크롤을 내려도 화면에 붙어 따라다닙니다.** 찌그러져 보이던 환경 설정 버튼도 바로잡았습니다. 펼치기 없이 한 번에 다 보이며, 창이 아주 낮을 때만 버튼 모음 안에서 스크롤됩니다.
- **"이미지 바로가기"와 "발행 바로가기" 버튼을 화면 위쪽 줄로 옮겼습니다.** 왼쪽부터 이미지 바로가기 · 발행 바로가기 · ⚙ · 비용표·추천 순서로, 같은 크기와 간격으로 정리했습니다. 스크롤을 내려도 늘 보입니다.
- 알림창이 이 버튼 줄 아래에 뜨도록 바꿔, 알림이 버튼을 가리지 않습니다.
- **이미지 바로가기를 누르면 이미지 관리의 소제목별 "이미지 프롬프트" 카드 화면으로 바로 이동합니다.** 이미지 생성 화면에 있었어도 이미지 관리로 돌아옵니다. 아직 글이 없어 카드가 없으면 이미지 탭 맨 위로 이동합니다.
- 오른쪽 아래에는 "메인 풀오토 이미지 설정" 버튼만 남겼습니다.
