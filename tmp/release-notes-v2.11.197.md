## v2.11.197

### 개선
- **홈판 제목 클릭 사유 개편** — "~정리/~현황/~포인트/~대응" 같은 요약 명사 종결 제목을 3중으로 차단(공식 풀 교체 + 채점 감점 + 프롬프트 금지). 제목 생성 전에 크롤링 원문에서 가장 의외의 사실·독자가 궁금해할 질문·클릭 이유를 먼저 추론하고, 모든 제목 후보를 그 클릭 사유에서 출발하도록 강제.

### 수정
- **텍스트 모델 선택 복원** — 앱 재시작 후 모델 라디오가 "선택 없음"이 되어 에이전트 모델 설정이 남은 상태에서 글 생성이 실패하던 문제. 저장된 선택을 시작 시점과 설정 모달 로드 시점에 복원.
