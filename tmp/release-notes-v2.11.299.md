## v2.11.299 — 완전자동·예약 발행 홈판 이미지 + 이미지 파이프라인 개편

### 추가
- **완전자동·예약 이미지 전략** — 글쓰기 모드(SEO·홈판·메이트 등)와 따로 고릅니다. 기본값 "홈판/피드 최적화"는 썸네일 1장 + 소제목마다 1장, 전부 800x800입니다(비율 설정을 따르지 않는 Flow·드롭샷 포함). SEO로 쓴 글에도 홈판용 이미지가 붙습니다. 위치: "메인 풀오토 이미지 설정" 창의 "완전자동·예약 이미지 전략", 연속발행 패널의 이미지 전략·소제목 범위·썸네일 문구.
- **이미지 검토 보류** — 풀오토·연속발행·다중계정에서 아래 경우에는 발행하지 않고 "이미지 검토 필요"로 둡니다. 글과 만들어진 이미지는 저장됩니다.
  - 썸네일 실패
  - 소제목 이미지 누락(홀수·짝수·없음 설정으로 뺀 소제목은 누락이 아닙니다)
  - 800x800이 아닌 썸네일
  - 고른 엔진이 아닌 모델로 만들어진 이미지
  - 이미지를 만든 뒤 소제목이 바뀐 경우
  - 반자동 발행에는 적용되지 않습니다.
- **예약 큐 상태** — 행마다 예약 날짜·시각, 글쓰기 모드, 이미지 전략, 글 ✓, 이미지 k/N, 최종 상태(READY / 이미지 검토 필요)를 보여 줍니다. 전역 "이미지 없음 / 글만 발행"이 켜져 있으면 큐 설정보다 우선하며, 행에 "이미지 없음(설정)"으로 표시하고 큐에 넣을 때 알려 줍니다. 발행 버튼 아래에 "글쓰기 모드 · 이미지" 한 줄, 진행 창에 썸네일 → 소제목 k/N 단계, 로그에 글마다 이미지 장수·예상 비용이 나옵니다.
- **썸네일** — 본문에 실제 사진이 있으면 AI 호출 없이 800x800으로 합성합니다. 두 사람 기사처럼 쓸 만한 사진이 2장 이상이면 좌우로 나란히 놓습니다. 사진이 없으면 제목과 클릭 사유로 표지 1장을 만듭니다. 문구는 제목 전체가 아니라 짧은 문구(AUTO / 포함 / 미포함)입니다.
- **한글 문구는 엔진이 직접** — 나노바나나2·나노바나나 프로·Flow·GPT 이미지·리더스 나노바나나는 썸네일 문구를 엔진이 그리고, 앱은 글자를 얹지 않습니다. 나노바나나 2.5는 기존처럼 앱이 문구를 얹습니다.
- **소제목 이미지 역할** — 소제목마다 다른 장면 역할(현장·비교·확대·절차·기준·장소·문제)을 배정하고, 이웃 소제목은 같은 역할을 쓰지 않습니다. 자동차 글은 증상→문제 부위, 가격·트림→비교, 옵션·기능→확대로 잡습니다. 동전 더미·돈다발·우산 아래 가족·네온 회로 같은 뻔한 컷은 금지합니다.

### 고침
- **소제목 이미지 홀수/짝수** — 홀수·짝수 모드에서 이미지 자리가 뒤바뀌거나 전부 빠지던 것. 소제목 1번이 홀수이고, 썸네일은 이 설정과 무관합니다.
- **이미지 재생성** — 🔄 재생성이 나노바나나2·Flow·ImageFX·드롭샷에서 네이버 검색 이미지로 빠지던 것. 고른 엔진으로만 다시 만들고, 네이버 검색은 직접 골랐을 때만 씁니다.
- **썸네일 문구 이중** — 엔진이 그린 문구 위에 앱 문구가 한 번 더 얹히던 것.
- **연속발행**
  - 이미지가 안 나온 글 1편에 큐 전체가 멈추던 것(재시도를 두 번으로 셈). 이제 2편 연속으로 이미지가 0장일 때만 멈춥니다.
  - 수정 창에서 바꾼 예약 시간이 무시되던 것.
  - 큐가 끝난 뒤 글쓰기 모드가 마지막 항목의 모드로 바뀌어 있던 것.
  - 홈판·업체·커스텀 글 제목 앞에 키워드가 강제로 붙던 것(체크했을 때만 붙습니다).
- **다중계정** — "이미지 없음"으로 둔 글에 제목만으로 이미지를 다시 만들던 것.
- **썸네일 자리** — 서론이 없는 글에서 1번 소제목 이미지가 썸네일로 쓰이던 것(풀오토·예약).
