## 리더스 나노바나나(드롭샷) 이미지 생성 복구

### 리더스 나노바나나
- 이미지가 만들어졌는데도 "결과 이미지 미발견"으로 실패하던 문제를 고쳤습니다. 드롭샷이 결과 이미지 주소 형식을 바꾼 것이 원인이었습니다.
- 결과를 기다리는 시간을 시도마다 90초에서 360초로 늘렸습니다. 생성이 오래 걸릴 때 기다리지 못하고 다시 누르는 일이 줄어듭니다.
- 로그인을 끝냈는데도 앱이 알아채지 못하던 경우를 고쳤습니다. 로그인이 되면 앱이 알아채고 생성 화면으로 넘어갑니다.
- 로그인 창이 이미 열려 있을 때 다시 누르면 빈 창이 여러 개 뜨던 문제를 고쳤습니다. "창이 이미 열려 있습니다"라고 한 줄로 안내합니다. 젠스파크에도 같은 처리를 넣었습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
