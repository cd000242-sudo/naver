## 이전글 카드 주소 글자 정리 · 계정 고르기 · 매일 예약발행 카테고리

### 고친 것
- 글 끝 이전글 카드 3개 위에 주소 글자가 그대로 남던 문제를 고쳤습니다. 이제 카드만 남습니다.
- 매일 예약발행 창에서 카테고리가 뜨지 않던 문제를 고쳤습니다(블로그 ID 칸에 블로그 이름이 들어 있는 계정). 카테고리를 못 불러오면 이유를 보여 줍니다.
- 같은 계정이 매일 예약발행 실행 단계에서 "블로그 ID 필요"로 멈추던 문제를 고쳤습니다.
- 환경 설정의 [공식 할당량 확인]을 누르면 창은 열리는데 "열지 못했습니다"라고 뜨던 문제를 고쳤습니다.

### 바뀐 것
- 에이전트 계정(Codex · Claude Code): 지금 쓰는 계정에 "✓ 사용 중"이 붙고, 다른 계정은 [이 계정 사용] 단추로 고릅니다. 빼기 단추는 계정마다 따로 있습니다.
- 하는 일이 겹치던 예전 [계정 전환] 단추는 숨겼습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
