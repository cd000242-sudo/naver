## v2.11.333 — 글쓰기 화면이 떴는데도 "연결 또는 화면 확인 필요"로 멈추던 문제 수정

### 바뀐 점
- **v2.11.326부터 발행이 글쓰기 화면에서 15~20초 기다린 뒤 "네이버 글쓰기 화면을 확인하지 못했습니다"로 멈추던 문제를 고쳤습니다.** 앱이 글쓰기 화면을 알아보는 기준이 실제 네이버 에디터 구조와 달라서, 화면이 떠 있어도 준비되지 않은 것으로 판단했습니다. 이제 실제 에디터 구조로 판단합니다.
- 로그인 아이디와 블로그 주소가 다른 계정에서, 발행 버튼을 직접 눌렀을 때 "다른 계정이 로그인돼 있다"로 잘못 멈출 수 있던 부분도 고쳤습니다.
- 이미 "연결 또는 화면 확인 필요"로 멈춰 있는 계정은 반자동으로 발행 버튼을 직접 누르면 로그인 상태를 확인한 뒤 이어서 발행합니다.
