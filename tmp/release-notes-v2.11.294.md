## v2.11.294 — 반자동 발행 원문 보존 + 썸네일 잔존 + 이미지 800x800

### 고침
- **반자동 발행 원문 보존** — 반자동 편집으로 넣은 글이 발행 직전 검사에서 숫자 문장(가격·수치)을 "근거 없음"으로 지우고, 빈 제목엔 "… 확인 가이드", 빈 소제목엔 "핵심 내용부터 살펴보기"를 채우던 것. 도입부 첫 줄·이미지 아래 첫 줄·마지막 줄 누락, "12.3"이 "12."에서 끊기던 것이 전부 같은 원인. 반자동 원고는 사용자가 쓴 그대로 나간다.
- **소수점 문장** — 전 모드에서 "12.3인치"처럼 숫자 사이 점이 문장 끝으로 취급돼 "12."가 매달리거나 "12. 3인치"로 공백이 끼던 것.
- **썸네일 잔존** — 썸네일 생성기 "적용하기" 후 발행하면 다음 글에도 같은 썸네일이 들어가던 것 (발행 완료 초기화가 진짜 전역을 비우지 않았다).
- **붙여넣기 제목** — 반자동 편집에 붙여넣을 때 `# 제목` / `**제목**` / `제목:` 첫 줄이 제목 칸이 아니라 소제목 1번이 되던 것. 제목 상한 60→80자.
- **붙여넣기 분류 엔진** — 자유 형식 글 분류가 Gemini 로 직행하던 것을 선택 엔진(GPT·Claude·에이전트)으로. 선택 엔진 키가 없으면 다른 벤더로 넘어가지 않고 알림.
- **외부 URL 이미지** — 302 리다이렉트를 실패로 취급해 3회 전부 건너뛰던 것. 리다이렉트 추적 + 핫링크 차단 페이지(HTML)를 이미지로 저장하지 않음.
- **번호 소제목** — "1. 제목" 형태의 소제목 줄이 소제목 패널에서 표기되지 않아 발행 구조가 0개가 되던 것.

### 추가
- **생성 이미지 800x800 자동 맞춤** — AI 생성 이미지(1:1·4:3·3:4)는 가운데를 잘라 800x800. 16:9·9:16 은 비율 유지 너비 800. 수집·다운로드 사진은 자르지 않음.
- **이미지 관리 탭 "AI 활용 체크하기"** — 켜면 발행 시 본문의 모든 이미지에 네이버 "AI 활용" 마크를 자동으로 켬 (기본 OFF).
