## 젠스파크 이미지 생성 복구

### 젠스파크
- 젠스파크가 모델 메뉴를 바꾸면서 이미지 생성이 "선택한 모델의 크레딧 정책이 바뀌었습니다"로 전부 멈추던 문제를 고쳤습니다. 이제 메뉴에 크레딧 배수(1× 등)가 표시돼도 멈추지 않고 생성합니다.
- 젠스파크는 더 이상 무제한 모델이 없습니다. 설정 화면의 모델 이름에 모두 「(크레딧 차감)」이 붙고, 요금제에 따라 크레딧이 줄어듭니다.
- 생성이 실패해도 같은 요청을 다시 보내지 않습니다(크레딧이 두 번 빠지지 않게).
- 젠스파크 화면에 안내 창이 떠서 단추를 가릴 때, 창을 닫고 이어서 진행합니다.
- 젠스파크가 "서버 과부하"로 거절하면 오래 기다리지 않고 바로 실패로 알려 줍니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
