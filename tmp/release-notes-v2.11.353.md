## v2.11.353 — CTA 여러 개가 하나만 남던 손실 지점 11곳 수정

### 바뀐 점
- **CTA별 위치("N번 소제목 아래")가 실제로 적용됩니다.** 앱 화면에서 행마다 고른 위치가 메인 프로세스 정규화 단계에서 버려져 전부 "전체 설정" 위치로 몰리고 있었습니다. 이제 `bottom` / `heading-N` 값이 에디터까지 전달됩니다.
- **링크만 넣고 문구를 비운 CTA 행도 발행됩니다.** 통합 화면 행 읽기·연속 발행 모달·다중계정·완전자동 경로 모두 문구 없는 행을 버리고 있었습니다. 이제 "자세히 보러가기" 기본 문구를 붙여 살립니다.
- **링크 없는 CTA(예: "댓글로 문의 주세요")가 하단에서 빠지지 않습니다.** 일반(SEO 등) 모드 하단은 링크 있는 CTA만 넣고 나머지는 아무 흔적 없이 건너뛰었습니다. 이제 구분선 + 문구로 삽입합니다. 소제목 아래 CTA도 링크가 없으면 "👉 #" 줄을 치지 않습니다.
- **쇼핑커넥트 모드의 "하단 CTA 1개 제한"을 없앴습니다.** 직접 추가한 2·3번째 CTA도 배너 아래에 링크 카드로 들어갑니다. 제휴링크와 같은 링크는 배너가 이미 담고 있으므로 건너뛰고, 같은 링크가 반복되면 첫 것만 넣어 카드 중복을 막습니다.
- **소제목 수를 넘는 위치(예: 소제목 3개인데 "5번 소제목 아래")의 CTA는 하단으로 보냅니다.** 전에는 어디에도 들어가지 않았습니다.
- **링크 카드 뒤 "URL 원문 정리"가 앞 CTA까지 지우던 문제를 고쳤습니다.** 카드가 생긴 뒤 남은 URL 글자를 지우는 코드가 문서 전체를 훑어 URL 문단이 든 **텍스트 컴포넌트를 통째로** 지웠습니다. 스마트에디터는 여러 문단을 한 컴포넌트에 담으므로 2번째 CTA를 넣는 순간 1번째 CTA의 구분선·문구(아직 카드가 안 뜬 URL 포함)가 사라져 **마지막 카드 하나만 남았습니다.** 이제 방금 넣은 URL 문단만 지웁니다.
- **연속 발행 상세설정 모달**: "CTA 유형"을 기본값(없음)으로 둔 채 CTA 행을 입력하면 행 전부가 버려지고 자동 이전글 카드만 끝에 남던 것을, 입력한 행이 있으면 자동으로 "직접 입력"으로 간주하도록 바꿨습니다. 다중계정 설정 모달도 같은 규칙(URL/문구를 넣었으면 CTA로 인정)입니다.
- **글 불러오기**가 CTA 행을 빈 칸으로 되살리던 것(행 클래스 불일치)을 고치고, 위치 선택도 함께 복원합니다. 다중계정 **계정 전환 시 세션 복원**도 위치 선택이 있는 정식 행으로 되살리고 링크만 있는 행을 버리지 않습니다.
- **앱 예약 발행**이 저장 글의 CTA를 하나도 싣지 않던 것을 고쳤습니다(ctas·문구·링크·위치·건너뛰기 전달).
- 발행 직전 "CTA 최종 확인"이 첫 CTA만 보던 것을 모든 CTA로 넓혔고, 빠진 CTA 문구를 로그에 적습니다.

### 확인한 사실
- 10/11~12 이 PC 발행 로그는 전부 `[TailOptions] CTA 1개`로 꼬리 단계에 도착했습니다(이전글 CTA 1개짜리). 다중 CTA 손실은 위 코드 경로 추적으로 확인한 것이며, 라이브 발행으로는 아직 검증 전입니다.
