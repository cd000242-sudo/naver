## 조화 모드 기본 적용 · 에이전트 글 검수 방식 선택 · 시작 화면 글씨 대비

### 에이전트 모드
- Claude Code · Codex 에이전트로 글을 만들 때 '조화 모드'가 기본으로 켜집니다. 에이전트가 글을 쓰면서 제목 후보 비교 · 앱 기준 자기 점검까지 한 번에 하고, 마지막에 독립 검수를 한 번 받습니다.
  - 예전처럼 제목 검수를 따로 돌리고 싶으면 환경설정 → 글생성 엔진 → '🤝 에이전트 글 검수 방식'에서 '기존 검수 방식'을 고르면 됩니다.
  - 자료 · 사실 검사와 그에 따른 다시 쓰기는 두 방식 모두 그대로입니다. 사진으로 글쓰기 · 매일 자동 발행은 기존 방식 그대로입니다.

### 화면
- 앱을 켤 때 뜨는 엔진 선택 창에서, 다크 화면일 때 이미지 엔진 이름과 설명이 잘 안 보이던 문제를 고쳤습니다. 다크 · 라이트 · 초록 · 파랑 모두 글씨가 바탕과 또렷이 구분됩니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
