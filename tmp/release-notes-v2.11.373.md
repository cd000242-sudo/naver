## 구독 에이전트 기본 · 매일 자동발행 백그라운드 · 새 화면

### 글 생성
- 글 생성은 구독 에이전트(Codex · Claude Code)를 기본으로 씁니다. 별도 API 키 없이 구독 한도로 글을 만듭니다.
  - Codex 기본 모델은 GPT-6.1 Terra, Claude Code 기본 모델은 Sonnet 5.5 입니다.
- 에이전트 연결을 버튼 하나로 합니다(준비 확인 → 설치 → 로그인 → 실제 답 확인). Codex CLI 는 0.166.0 으로 맞춥니다.
- 앱을 켤 때 뜨는 엔진 선택 창에서 글 엔진(왼쪽)과 이미지 엔진(오른쪽)을 함께 고릅니다.
- API 키 엔진을 최신 모델로 바꿨습니다.
  - OpenAI: GPT-6 Luna · GPT-6.1 Terra · GPT-6.1 Sol
  - Claude: Sonnet 5.5 · Fable 5.1 · Haiku 5.5
  - Gemini: 3.8 Flash · 3.5 Flash-Lite (3.5 Flash-Lite 는 3.1 Flash-Lite 보다 단가가 높습니다)
- API 키 설정은 네이버 검색 API(HUB·기존 키) · 네이버 검색광고 · OpenAI · Gemini · Claude · Perplexity · 젠스파크 · 드롭샷만 남겼습니다.
- 추가 요청사항이 글에 그대로 반영되도록 고쳤습니다.

### 매일 자동발행
- 매일 자동발행이 켜져 있으면 창을 닫아도 트레이에서 계속 실행됩니다. 완전히 끄려면 [완전 종료] 또는 트레이 메뉴의 "앱 완전 종료"를 누르세요.
- 단일 · 연속 · 다중계정 발행과 겹치면 실패하지 않고 차례를 기다렸다가 이어서 발행합니다. 연속발행의 [중지]는 매일 자동발행을 멈추지 않습니다.
- 예약 시각을 놓친 글은 데스크톱 알림으로 알려 드립니다.
- 'LEWORD 오늘의 추천' 키워드로 주제와 시간대만 정하면 키워드부터 예약까지 자동으로 진행합니다.

### 이미지
- 새 이미지 엔진 'Codex 구독 이미지(GPT 이미지)': ChatGPT 구독의 이미지 도구로 그립니다. 별도 비용이 없고 구독 한도를 씁니다. 설정한 비율(기본 1:1)을 따릅니다.
- 새 이미지 엔진 '관련 사진 찾기(뉴스 · 기사 사진, 무료)': 저작권 안내에 동의한 뒤 글과 맞는 뉴스 사진을 찾고 출처를 표시합니다. 맞는 사진이 없으면 빈 칸으로 둡니다.
- 이미지 관리 탭과 풀오토 이미지 설정이 하나의 설정으로 함께 바뀝니다.
- '소제목 텍스트 포함하기' 체크박스: 소제목 이미지에 소제목 글자를 그대로 넣습니다(한글을 직접 그리는 엔진만).
- 사진 수집은 제목 · 본문 · 소제목을 함께 분석해 찾습니다.
- 젠스파크 · Codex 구독 이미지 · 관련 사진 찾기를 엔진 목록 맨 위에 두었습니다.
- 지원이 끝난 이미지 엔진(Leonardo · DeepInfra · Prodia 등)을 고른 상태였다면 처음 생성할 때 다른 엔진을 고르는 창이 뜹니다.

### 화면 · 계정
- 흰 바탕 + 네이버 초록 화면으로 바꿨습니다. 선택한 항목은 연보라로, 진행 창 · 안내 창은 밝은 색으로 표시합니다.
- 앱 안 '네이버 계정 연결' 패널에서 계정별 로그인 상태를 보고 로그인 창을 엽니다.

### 수정
- Codex 로 글 · 이미지를 만들 때 터미널(cmd) 창이 계속 뜨던 문제를 고쳤습니다.
- 젠스파크가 로그아웃 상태인데 "로그인됨"으로 보이던 문제를 고쳤습니다.
- 앱이 켜지는 도중에 창을 닫으면 확인창 없이 꺼지면서 "앱 초기화 오류 · HTML 로드 실패" 창이 뜨던 문제를 고쳤습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
