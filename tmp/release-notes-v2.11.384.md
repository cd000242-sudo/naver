## 소제목 앞에 엉뚱한 낱말이 붙던 문제 수정

### SEO · 네이버 메이트 글
- 소제목 앞에 키워드 핵심어를 붙일 때, 키워드에 들어 있던 **날짜·금액·인용 문구 조각**을 붙이던 문제를 고쳤습니다.
  - 예: 키워드 "11월 6일까지 접수" 부산시 … → 소제목 "6일까지 동백전 앱 신청 경로" (이제 이런 조각을 붙이지 않습니다)
  - 예: 키워드 '○○ 인기투표 1위' 손석구 … → 따옴표 안 낱말이 소제목 앞에 붙던 것
  - 예: "2026 청년도약계좌 조건" → "2026 …", "3140만원 신형 투싼" → "3140만원 …"
- 이제 따옴표·괄호 안 문구와 숫자로 시작하는 낱말은 붙이지 않고, 붙일 낱말이 마땅치 않으면 소제목을 그대로 둡니다.

### 홈판 글
- "결승까지 가야 했던 조건"이 "가야 했던 조건"으로 잘리던 문제를 고쳤습니다. "○○까지" 뒤가 동작으로 이어지면 자르지 않습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
