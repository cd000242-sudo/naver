## v2.11.350 — 발행 크롬이 "다른 기계"로 보이던 문제 해결 (보호조치 원인)

### 바뀐 점
- **앱이 띄우는 발행 크롬이 이제 사장님이 쓰는 크롬과 같은 PC로 보입니다.** 그동안 앱은 크롬의 그래픽카드·CPU 코어 수·메모리·윈도우 버전·브라우저 세부 버전·화면 크기·언어·알림 권한·WebRTC·카메라 정보를 가짜 값으로 바꿔 보고하고 있었습니다. 실제로 재 보니 사장님 크롬과 81개 항목 중 26개가 달랐고, 윈도우 PC가 맥 그래픽카드 이름을 보고하는 등 앞뒤도 맞지 않았습니다. 네이버에는 한 아이디가 "진짜 PC"와 "변조된 다른 PC"를 번갈아 쓰는 것으로 보였고, 이것이 로그인할 때 보호조치가 뜨던 원인입니다.
- 가짜 값을 전부 걷어냈습니다. 남긴 것은 자동화 표시 제거(크롬이 "자동화 중"이라고 알리는 플래그만 끔)와 계정별 로그인 유지뿐입니다. 프록시를 쓸 때만 WebRTC로 실제 IP가 새지 않게 막습니다.
- 크롤러·이미지 엔진이 쓰는 위장 플러그인이 발행 크롬에 묻어 들어가지 않도록 발행 크롬은 순정 puppeteer로 띄웁니다.
- 앱 크롬 프로필의 언어가 영어(en-US)로 심겨 있던 것을 한국어 크롬 기본값(ko-KR, ko, en-US, en)으로 바로잡습니다. 기존 프로필도 다음 실행 때 자동으로 고쳐집니다.
- 고친 뒤 같은 측정을 다시 했습니다. 기기 정체성 항목(그래픽카드·CPU·메모리·OS·브라우저 버전·브랜드·언어·권한·WebRTC·카메라)은 사장님 크롬과 전부 같아졌고, 남은 차이는 창 크기·위치 같은 세션마다 달라지는 값뿐입니다.

### 알아두실 점
- 한 PC에서 여러 계정을 쓰면 이제 모든 계정이 "같은 PC"로 보입니다. 실제 사람이 블로그 두 개를 쓰는 모습과 같습니다.
- 이미 보호조치가 걸린 계정은 네이버 안내대로 먼저 해제해야 합니다. 이 변경은 앞으로 새로 걸리는 것을 막는 쪽입니다.
- 같은 아이디를 아버님 노트북과 사장님 PC에서 번갈아 로그인하는 것은 여전히 "새 기기 로그인"으로 보이므로 한 곳에서만 쓰는 것이 안전합니다.
