## v2.11.349 — 발행할 때 타이핑 크롬 창을 맨 앞으로

### 바뀐 점
- **발행을 시작하면 타이핑하는 크롬 창이 맨 앞으로 뜹니다.** 반자동·풀오토·연속발행·예약·다중계정 등 모든 발행에 적용됩니다. 전에는 첫 발행이 끝나면 크롬 창을 숨겨 두고, 다음 발행에서도 숨긴 창에서 그대로 타이핑했습니다.
- **"⌨️ 타이핑 보러가기" 버튼을 누르면 크롬 창이 화면에 제대로 나타납니다.** 창이 화면 밖으로 밀려나 있던 경우에는 버튼을 눌러도 창이 화면 밖에 남아 보이지 않았는데, 이제 화면 안으로 되돌려 최대화합니다.
- 발행이 끝나면 지금처럼 크롬 창을 숨깁니다(실수로 닫는 것 방지).
- LDB에서 이미지를 앱에 배치할 때 걸린 시간(카테고리 확인 · 이미지 파일 저장 · 앱 화면 반영)과 그때 앱 창 상태를 로그에 남깁니다. 배치가 느린 원인을 찾기 위한 기록입니다.

### 알아두실 점
- 게임이나 다른 작업 중에 예약·연속발행이 시작되면 화면이 크롬 창으로 바뀝니다.
- 다중계정 발행은 계정마다 크롬 창이 앞으로 뜹니다.
