## v2.11.341 — 이미지 엔진 정리 · 기본값 덕트테이프 · 바로가기 버튼

### 바뀐 점
- **이미지 엔진을 정리했습니다.** 나노바나나는 최신 **나노바나나2** 한 가지만 남겼습니다. 이전에 나노바나나 프로나 나노바나나(2.5)를 쓰고 계셨다면 자동으로 나노바나나2로 바뀝니다.
- **덕트테이프(GPT 이미지)는 gpt-image-2.5 Sunburst(품질형)와 Flare(속도형) 두 가지만** 남겼습니다. 기본값은 Sunburst입니다. 예전 모델(gpt-image-1·1.5·2)을 쓰고 계셨다면 자동으로 Sunburst로 바뀌고, Flare를 직접 고르셨다면 그대로 유지됩니다.
- **처음 쓰시는 분의 기본 이미지 엔진은 덕트테이프입니다.** 이미 엔진을 골라 두셨다면 바뀌지 않습니다. 덕트테이프는 OpenAI API 키가 필요합니다.
- **"발행 바로가기" 버튼을 오른쪽 아래로 옮겼습니다.** 오른쪽 위 알림창에 가려지던 문제를 없앴습니다. "⚡ 메인 풀오토 이미지 설정" 버튼 바로 위에 있습니다.
- **"🖼️ 이미지 바로가기" 버튼을 새로 넣었습니다.** 누르면 이미지 생성·관리 탭으로 바로 이동합니다. 두 버튼 모두 크고 잘 보이게 만들었습니다.
- 덕트테이프 예상 비용 안내가 실제보다 크게 표시되던 것을 바로잡았습니다.
