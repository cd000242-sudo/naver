## v2.11.346 — 젠스파크 반자동·이미지 관리 탭도 여러 장 동시 생성

### 바뀐 점
- **반자동 발행과 이미지 관리 탭의 'AI 이미지 생성' 버튼도, 젠스파크를 고르면 소제목 이미지를 한 번에 요청해 최대 4장씩 동시에 만듭니다.** 풀오토·연속 발행·다중계정은 지난 버전부터 같은 방식입니다.
- 한 번에 요청한 이미지 중 일부가 실패하면, 받은 이미지는 그대로 쓰고 실패한 소제목만 한 장씩 다시 만듭니다.
- 이미지 엔진에서 젠스파크를 고르자마자 이미지 생성을 누르면 "젠스파크 전용 크롬이 이미 열려 있습니다"로 실패하던 문제를 고쳤습니다. 이제 로그인 확인이 끝나길 기다렸다가 이어서 만듭니다.
