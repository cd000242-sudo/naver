## 다크 화면 선택 · 글 생성 안 끊김 · 로그 색

### 화면
- 왼쪽 위 제목 옆에서 라이트 / 다크 화면을 고를 수 있습니다. 고른 화면은 이 PC 에 기억됩니다.
  - 다크는 예전처럼 검은 바탕이고, 버튼은 초록 그대로입니다.
  - 종료 확인 창 · 계정 관리 창처럼 따로 뜨는 창은 아직 라이트로만 보입니다.
- 로그 글자색: 라이트에서는 녹색, 다크에서는 예전 노란색입니다. 실패는 빨강, 경고는 주황으로 그대로 구분됩니다.

### 글 생성
- 홈판 글을 직접 [글 생성]할 때, 마지막 제목 검수에서 "DAILY_TITLE_QUALITY … 다른 소재를 선택해 주세요"가 뜨며 다 만든 글이 사라지던 문제를 고쳤습니다.
  - 이제 글은 그대로 두고, 제목이 약하다는 판정과 검수 의견을 경고로 보여 드립니다. 발행 전에 제목을 확인하거나 바꿔 주세요.
  - 매일 자동발행(사람이 보지 않는 발행)은 지금처럼 이런 글을 보류합니다.
- 개인 프롬프트(자유 문장)가 긴 기본 지침에 묻혀 적용되지 않던 문제를 고쳤습니다. 글을 쓰기 직전에 개인 프롬프트를 한 번 더 확인합니다.

### 수정
- 네이버 검색 API 가 호출 한도(429)에 걸리면 다른 키(API HUB ↔ 기존 개발자센터 키)로 한 번 더 시도합니다. "SEARCH_RATE_LIMITED"가 덜 뜹니다.
- 앱을 끌 때 파워셸 창이 잠깐 뜨던 문제를 고쳤습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
