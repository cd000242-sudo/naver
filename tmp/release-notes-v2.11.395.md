## 노출 측정용 검색어 자동 채우기 · 홈판 제목 규칙

### 노출 측정
- 키워드 칸을 비워 두고 글을 만들어도, 앱이 글에서 검색어를 골라 노출 순위를 잽니다. 지금까지는 칸이 비면 제목으로 색인 여부만 확인했습니다.
- 네이버 월간 검색량이 확인된 검색어만 순위 측정에 씁니다. 검색량을 확인하지 못하면 예전처럼 제목으로 색인만 확인합니다(검색광고 API 키가 설정돼 있어야 검색량을 확인할 수 있습니다).
- 직접 넣은 키워드(키워드 칸, LEWORD, 예약 작업)가 있으면 언제나 그것으로 잽니다.
- 주소 없이 제목만 넣어 만든 글과 예약 발행 글에도 적용됩니다. 이 경우 글을 만든 뒤 검색어를 고르는 보조 호출이 한 번 더 들어갑니다(선택한 엔진 사용, 최대 45초, 실패해도 발행에는 영향이 없습니다).
- 자동으로 고른 검색어는 글 내용을 바꾸지 않습니다. 측정에만 씁니다.

### 홈판 글쓰기
- 제목에 숫자를 쓸 때 무엇의 숫자인지 대상을 함께 적습니다(예: "3배" 대신 "관객 3배").

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
