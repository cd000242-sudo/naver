## 홈판 글쓰기 규칙 개선 · 클로드 코드 글 SEO 점검

### 홈판 글쓰기
- 홈판 제목·문단·문장 규칙을 새 홈판 지침(v5.2)에 맞췄습니다. 제목은 "후킹 + 키워드·구체 정보" 두 단으로, 문단은 3문장 안팎으로, 문장은 80자를 넘기지 않게 씁니다.
- 기계식 도입("오늘은 ○○에 대해 알아볼게요")·기계식 마무리·기사체 상투어를 쓰지 않습니다.
- 소제목은 4~6개(패션은 3~4개), 홈판 제목 길이는 25~40으로 바꿨습니다.
- 건강·IT·리빙·패션·방송·가십·스포츠 글에 주제별 주의 규칙을 더했습니다.
- 스포츠 글이 스포츠용 홈판 규칙을 받지 못하던 문제를 고쳤습니다.

### 클로드 코드로 만든 글
- 글을 만든 뒤 claude-seo 스킬 기준(답 먼저·인용되기 쉬운 문장·읽기 쉬움)으로 한 번 점검하고, 분명히 부족한 곳만 고칩니다.
- 숫자·고유명사·제목·소제목 제목은 바꾸지 않고, 홈판 글은 도입부도 그대로 둡니다.
- 점검이 실패하거나 오래 걸리면 점검 전 글로 그대로 발행합니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
