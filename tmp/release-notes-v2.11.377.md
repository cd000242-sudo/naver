## 에이전트 조화 모드 준비 (기본 꺼짐)

### 에이전트 모드
- 에이전트(Claude Code · Codex)가 홈판 글을 쓸 때 한 번의 작업 안에서 다음을 모두 하는 '조화 모드'를 넣었습니다.
  - 자료 분석 → 독자 질문 정하기 → 제목 후보 비교 → 글쓰기 → 앱 기준으로 스스로 점검 → 지침끼리 부딪히는 곳 보고
- 조화 모드가 켜지면 바깥에서 따로 돌던 제목 후보 비교(4번 호출)와 다시 쓰기를 건너뛰고, 다른 세션에서 독립 검사를 1번만 합니다.
- **이번 버전에서는 꺼져 있습니다.** 지금 쓰시는 방식과 똑같이 동작합니다. 사장님 PC에서 실측해 기준을 넘으면 다음 버전에서 켭니다.
- 자료와 사실을 지키는 검사(숫자 · 인용이 원문에 있는지, 명예훼손 소지, 자료를 무시한 글 다시 쓰기)는 그대로입니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
