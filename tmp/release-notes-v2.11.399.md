## 생성된 글 목록이 비어 보이던 문제

### 고친 것
- 앱이 느리게 켜질 때 "생성된 글 목록"이 빈 화면으로 뜨고, 탭을 다시 눌러도 계속 비어 있던 문제를 고쳤습니다. 글은 지워지지 않았고 화면만 안 바뀌던 것입니다.
- 달력에서 메모를 적어 둔 날짜에 표시 점이 안 보이던 문제를 고쳤습니다.
- CTA 위치 선택 문구를 실제 동작에 맞게 "하단 (해시태그 앞)"으로 바꿨습니다. 발행 순서는 그대로입니다.

업데이트 뒤에도 글 목록이 비어 보이면 알려 주세요.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
