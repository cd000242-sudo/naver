## v2.11.319 — 글 1편당 글쓰기 화면 진입 1회

### 바뀐 점
- **글쓰기 화면을 여러 번 다시 열지 않습니다.** 예전에는 글 1편을 쓰는 동안 단계마다 화면을 못 찾으면 글쓰기 화면을 다시 불러와, 많게는 10번 넘게 열었습니다. 이제는 한 번 열고 에디터가 다 뜰 때까지 기다립니다. 끝내 안 뜨면 딱 한 번만 다시 엽니다.
- **발행 재시도를 줄였습니다.** 발행·예약 단계는 같은 화면에서 최대 1번만 다시 시도합니다. 앱이 글 전체를 처음부터 다시 돌리는 경우는 브라우저 자체가 꺼졌을 때뿐입니다.
- **순차 다중계정: 실패한 계정을 '발행 성공'으로 기록하던 문제를 고쳤습니다.** 계정별 실제 결과로 판정하고, 오류가 난 뒤에도 설정한 발행 간격을 지킵니다.
