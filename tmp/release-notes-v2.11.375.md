## 글 생성 속도 · 이미지 재생성

### 글 생성
- 홈판 글을 [글 생성]할 때 다 쓴 글을 처음부터 한 번 더 쓰던 문제를 고쳤습니다.
  - 개인 프롬프트를 쓰지 않았는데도 앱 내부 지시문을 '사용자 프롬프트'로 잘못 채점해 "반영 부족"으로 다시 썼습니다.
  - 이제 사장님이 직접 쓴 개인 프롬프트만 확인합니다. 글을 쓰는 지시는 그대로입니다.
  - 에이전트 모드(Claude Code · Codex)에서는 다시 쓰기 한 번이 약 3분이었고, 제목이 바뀌는 글은 두 번 다시 썼습니다.

### 이미지
- 이미지 관리 탭과 소제목 이미지의 [재생성]이 처음 만들 때와 같은 설정으로 다시 그립니다.
  - 같은 영어 장면 프롬프트, 소제목 이미지에는 글자 없음, 참고 이미지, 글 제목을 그대로 씁니다.
  - 썸네일 재생성은 '썸네일 텍스트 포함' 체크를 따릅니다.
  - 장면 프롬프트가 없는 칸은 소제목으로 만들고, 그렇다는 안내를 로그에 남깁니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
