- 쇼핑 글을 쓰다가 "표 이미지 생성 중…"에서 멈추던 문제를 고쳤습니다. 표에 넣을 내용을 20초 안에 받지 못하면 표만 건너뛰고 글쓰기를 계속합니다.
- 쇼핑 글을 다시 발행할 때 제휴 링크가 빠져 일반 글로 올라가던 문제를 고쳤습니다. 제휴 링크 칸이 비어 있으면 글에 저장된 링크로 발행하고, 링크를 찾지 못하면 발행 전에 확인 창으로 알려 드립니다.
- 쇼핑 글을 AI 이미지로 만들 때 대표 상품 사진이 이미지 관리 탭에 보이지 않던 문제를 고쳤습니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
