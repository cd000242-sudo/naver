## v2.11.336 — 발행이 멈추던 문제 묶음 수정 + 계정 관리 창

### 바뀐 점
- **계정이 맞는데 "선택한 계정과 다른 네이버 계정이 로그인돼 있습니다"로 막히던 문제를 고쳤습니다.** 네이버 로그인 아이디와 블로그 주소가 다른 계정(예: 아이디 abc, 블로그 주소 xyz)은 그동안 항상 막혔습니다. 이제 첫 발행 때 실제 블로그 주소를 확인해 기억하고, 그 블로그로 발행합니다. 정말 다른 계정이 로그인돼 있을 때만 멈추고, 어떤 블로그인지 이름을 알려 드립니다.
- **글은 올라갔는데 "직전 글이 발행됐는지 확인되지 않았습니다"로 계정이 멈추던 문제를 고쳤습니다.** 발행이 확인되는 즉시 기록해서, 그 뒤 단계에서 오류가 나도 멈추지 않습니다. 발행 직후 다른 주소로 잠깐 넘어가는 경우에도 최대 30초까지 실제 글 주소를 기다립니다.
- **발행 버튼 누르기 직전에 이유 없이 멈추던 것을 줄였습니다.** 로그인 풀림·본인확인·보호조치처럼 확실한 경우에만 멈춥니다.
- **계정이 멈추면 그 자리에 안내 창이 뜹니다.** "직전 글이 올라갔나요?" 창에서 [네이버 글 목록 열기] [올라갔어요] [안 올라갔어요]를 눌러 바로 풀 수 있습니다. 메인 화면에서 아이디를 직접 입력해 쓰는 경우도 풀 수 있습니다.
- **연속발행·다중계정 발행:** 계정이 멈추면 연속발행은 이유를 보여 주고 바로 멈춥니다. 다중계정은 멈춘 계정만 건너뛰고 나머지 계정은 계속합니다. (보호조치·본인확인은 안전을 위해 전체를 멈춥니다.)
- **본문이 두 번 들어가던 문제와 이미지가 두 장씩 들어가던 문제를 막았습니다.** 느린 컴퓨터에서 붙여넣기나 이미지 업로드가 늦게 끝나면 실패로 보고 한 번 더 넣던 것을, 늦게 들어오는지 기다렸다가 확인하도록 바꿨습니다.
- **⚙️ 계정 관리 창이 생겼습니다.** "➕ 계정 추가" 옆 버튼에서 저장된 계정의 별명·블로그 주소·아이디·비밀번호를 고치거나 삭제할 수 있고, 멈춘 계정은 [풀기]로 풀 수 있습니다. 앱은 비밀번호를 자동으로 입력하지 않으니, 비밀번호를 바꾸셨다면 다음 발행 때 열리는 네이버 창에서 한 번 직접 로그인해 주세요.
- **종료 창에서 [계속 사용]을 한 번 누른 뒤 다시 종료하면 앱이 멈추던 문제를 고쳤습니다.**
- **발행이 실패하거나 취소될 때마다 바탕화면에 진단 파일이 쌓이던 것을 없앴습니다.** 원인 확인이 필요할 때만 화면의 [🔧 오류 진단 저장] 버튼으로 만들어 보내 주세요.
- **네이버 API HUB 키:** 저장하면 "✅ 네이버 API HUB 키 저장됨" 문구가 뜹니다. 9월 30일 업데이트 때 지워진 키는 저절로 돌아오지 않으니, 이번 업데이트 후 HUB 키를 한 번만 다시 넣고 [API 키 저장]을 눌러 주세요. 그 뒤로는 업데이트해도 유지됩니다.
