## v2.11.329 — 반자동 발행 시 멈춘 계정 자동 확인

### 바뀐 점
- **반자동 발행 버튼을 직접 누르면, 멈춰 있던 계정을 앱이 먼저 확인합니다.** 지금까지는 이전에 한 번 실패한 계정이 "계정 관리에서 상태 확인 후 직접 재개해 주세요"로 계속 막혔습니다. 이제는 버튼을 누르면 로그인 상태를 확인해서, 로그인이 살아 있으면 멈춤을 풀고 그대로 발행합니다.
- **로그인이 만료된 계정은 그 계정의 네이버 로그인 창을 앞으로 띄웁니다.** 그 창에서 직접 로그인한 뒤 발행 버튼을 다시 누르면 됩니다. 앱이 비밀번호를 대신 입력하지는 않습니다(보호조치 방지).
- 본인확인·보호조치·다른 계정 로그인·직전 글 발행 여부 불명처럼 사용자가 판단해야 하는 경우에는, 계정 관리에서 눌러야 할 버튼 이름을 정확히 안내합니다.
- 연속발행·다중계정·예약 발행은 지금처럼 계정이 멈추면 멈춥니다(사람이 없는 동안 로그인 창을 띄우지 않습니다).
