## 글쓰기 속도 · 해시태그는 발행 태그 칸으로 · AI 활용 표시 · 썸네일 글자

### 글쓰기 (에이전트 모드)
- Claude Code 에이전트의 본문 쓰기가 크게 빨라졌습니다. 같은 글로 재 본 본문 쓰기 시간이 약 8분에서 약 2분 안쪽으로 줄었습니다.
  - 에이전트가 답하기 전에 지나치게 오래 생각하던 것을 줄이고, 조화 모드에서 "통과할 때까지 반복"을 "한 번 고쳐 제출"로 바꿨습니다.
  - 답이 길어져 앞부분이 잘리고 글을 처음부터 다시 쓰던 문제가 함께 사라졌습니다.
- 글쓰기 지시에 넣던 최근 글 목록을 최신 15편으로 줄였습니다. 발행 후 중복 검사는 그대로 50편과 비교합니다.

### 해시태그
- 해시태그가 본문 끝 글자가 아니라 네이버 발행 화면의 태그 칸에 들어갑니다(즉시 발행 · 예약 발행). 발행 직전에 태그 칸에 들어간 것을 확인한 뒤 본문의 해시태그 줄을 지우고, 빠진 태그가 있으면 태그 칸에 직접 넣습니다. 임시저장은 그대로입니다.

### AI 활용 표시
- "AI 활용 체크하기"를 켜도 표시가 안 되던 문제를 고쳤습니다. 표시 버튼이 화면 밖에 있어 누르지 못하던 것이 원인이었고, 버튼을 화면 안으로 옮겨 누른 뒤 켜졌는지 확인합니다. 이미지마다 최대 3번 다시 시도합니다.

### 이미지
- 이미지 관리 탭에서 썸네일을 만들거나 다시 만들 때 제목 글자가 빠지던 문제를 고쳤습니다(풀오토와 같게).

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
