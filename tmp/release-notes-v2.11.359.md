## v2.11.359 — 심층 리서치 2단계: 독자 질문으로 쪼개 찾고, 빠진 질문만 한 번 더 찾기

### 바뀐 점
- **질문 분해 검색(A3).** 키워드로 글을 생성할 때, 선택한 글 생성 엔진의 저비용 모델에 1회 물어 독자가 실제로 묻는 검색어 5~8개(조건·금액·절차·기한·예외·비교·확인처)를 뽑고, 각 검색어로 뉴스·블로그를 추가 검색해 기본 후보 뒤에 붙입니다. 기본 검색과 동시에 돌아 시간은 거의 더 들지 않습니다. 엔진 미선택·키 없음·구독 CLI(Codex/Claude/Gemini CLI)는 느리거나 경로가 없어 이 단계를 건너뛰고 기본 수집만 합니다(다른 벤더로 넘어가지 않음).
- **빠진 질문 보충(A4, 모델 호출 없음).** 1차 수집이 끝난 뒤 수집 본문이 아직 답하지 않은 질문(핵심어가 본문에 없는 것)을 코드로 골라 최대 3개만 2차 검색하고, 남은 시간·건수·글자 예산 안에서만 더 모읍니다.
- 로그에 `[심층 리서치] 질문 분해(모델) N개: …`, `[심층 리서치] 빠진 질문 K개 → 2차 후보 M건`, `2차 수집 N건 추가`가 찍힙니다.

### 확인한 사실
- 비용: 편당 저비용 모델 호출 1회(입력 약 300자, 출력 최대 300토큰) 추가. 본문 호출은 그대로입니다.
- 품질 변화는 저장된 글·하네스로 전/후 비교할 예정이며 추정 효과는 적지 않습니다.
