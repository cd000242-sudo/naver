## 에이전트 계정 골라 쓰기 · 멈춘 발행 이어서 하기

### 새로 된 것
- 환경 설정 맨 위에 에이전트 카드(Claude Code · Codex · Antigravity)를 모았습니다. 카드마다 로그인한 계정의 이메일과 플랜이 보입니다.
- Codex · Claude Code 는 계정을 여러 개 저장해 두고 골라 쓸 수 있습니다([+ 계정 추가] · [이 계정 빼기]). Antigravity 는 [다른 계정으로 로그인]으로 바꿉니다.
- 글이나 이미지 생성이 한도 초과 · 로그인 만료 · 모델 오류로 멈추면 창이 뜹니다. [같은 모델로 이어서] · [다른 모델로 바꿔서 이어서] · [여기서 멈추기] 중에 고르면 됩니다. 이미 만든 글과 이미지는 다시 만들지 않습니다.
- 앱을 껐다 켜도 화면 오른쪽 아래 "이어서 발행" 카드에서 멈춘 발행을 이어 갈 수 있습니다(풀오토 · 연속 발행 · 다중계정).
- 처음 설치하면 글쓰기는 Claude Code, 이미지는 Codex 가 기본으로 잡힙니다. 이미 쓰던 설정은 바뀌지 않습니다.

### 고친 것
- 쇼핑 글에서 이미지가 한 장 빠지면 통째로 멈추던 것을, 빠진 칸만 다시 만들도록 고쳤습니다.
- Codex 이미지가 실패했을 때 진짜 이유(한도 · 로그인 등)가 화면에 나오지 않던 문제를 고쳤습니다.
- API 키 칸은 접어 두었습니다. 필요할 때 펼쳐서 고치면 됩니다.

Windows x64 업데이트입니다. 설치 후 앱을 다시 실행해 주세요.
