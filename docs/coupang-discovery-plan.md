# 쿠팡: 검색 공략과 상품 발견 분리

## 사용자 의도
검색량이 적거나 검색 경쟁이 높다고 신기하고 실용적인 쿠팡 상품까지 제외하지 않는다. 기존 UI, 다른 제휴 플랫폼의 판정, 수집 비용과 API 호출 수는 유지한다.

## 이번 변경
- 쿠팡 기본 보기는 신기·실용 탐색. 상품명의 구체적인 기능 표현과 해당 기능의 사용 용도가 함께 있는 상품을 먼저 보여준다.
- 최근 48시간 이내 API 목록 관측, 인식 가능한 수집 출처, 유효한 가격과 쿠팡 링크를 확인한다.
- 검색량·문서수는 별도 검색 유입형 판정에만 사용한다. 검색 공략 보류는 상품 자체의 탈락이 아니다.
- 발견형의 표시는 조사 후보이며 실제 성능·신제품 여부·판매량·구매전환을 검증했다는 주장이 아니다. 골드박스는 특가 목록이고, API 응답 순서를 실제 판매 순위로 표현하지 않는다.
- 단서가 없는 상품도 전체 상품에서 보존한다. 상품명 기반 질문을 제공하되 허위 사용 후기나 성능 제목을 만들지 않는다.

## 범위와 남은 근거
현재 API는 상품명·가격·이미지·목록 출처를 제공한다. 상품 상세 본문, 리뷰 증가율, 영상 사용 장면, 클릭/주문 성과는 이번 변경에 새로 수집하지 않는다. 따라서 이 단계는 발견 후보를 복원하는 분류 수정이지, 실제 인기와 전환이 검증된 최종 추천 엔진이 아니다. Bright Data나 추가 유료 호출은 사용하지 않는다.

## 검증
저검색량/고경쟁 독립성, 마케팅 문구와 기능-용도 불일치 방어, 만료·가격·출처·URL 검증, 특가≠판매 순위, 결정적 정렬을 단위 테스트한다. 기존 제휴·실검 테스트와 SPA 빌드, 독립 코드/보안 검토를 수행한다.

## 서버 필터 보완
독립 검토에서 운영 Worker가 정면 제목 6개 이상인 상품을 응답 전에 제거하는 것을 확인했다. `scripts/coupang-worker-patch.mjs`는 해당 필터를 없애고 최근 24시간 관측 최대 80개를 유지하며 캐시 버전을 변경한다. 추가 수집 호출은 없다. 현재 배포 코드를 조회해 정확한 대상 블록만 수정하며, 낡은 로컬 Worker 전체를 업로드하지 않는다. `scripts/coupang-worker-release.mjs`는 SHA 확인·변경 전 백업 후 Cloudflare의 코드 전용 `/content` API를 사용하고 배포 후 코드와 바인딩/설정 보존을 확인한다.

## 로컬 UI 검증
`cd spa && npm run dev -- --host 127.0.0.1 --port 5128 --strictPort` 후 `/tests/coupang-discovery.html`에서 합성 데이터 4개를 사용한다. 외부 호출은 모의 응답과 CSP로 차단한다. 전체4→기능단서2→검색공략보류3→기능단서2 복귀, 글 구성 펼치기, 전환 중 모의 API 추가 호출 없음, 화면 오류0을 확인했다. 테스트 진입점은 프로덕션 빌드에 포함하지 않는다. 이미지가 없는 상품도 카드의 이미지 칸을 유지하도록 보완했다.
